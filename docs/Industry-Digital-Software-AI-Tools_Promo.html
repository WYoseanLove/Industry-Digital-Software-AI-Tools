Five products, one workflow

Tecnomatix, NX, Vismockup, CATIA V5 and Office share the same runner conventions.

Auto environment detection

One script finds installed software and versions dynamically; only USABLE tools are used.

一键检测软件与版本，仅 USABLE 可用

Self-learning memory

Corrections and pitfalls are recorded in Memory/ and gated before every run.

Version adaptive
