# 19 · Create a Human with a given gender and height / 创建指定性别和身高的人体

> **When to use / 何时使用**
> Add a new Jack/Jill human (e.g. a 180 cm female) to the open Study, place it where an existing human stands,
> and read the result back. 在已打开的仿真中新增一个人体（如 180 cm 女性），放到已有人体的位置并回读验证。
>
> **Keywords / 关键词**: TxHuman, Jack, Jill, create human, Create Human command, female, gender, height,
> stature, AbsoluteLocation, GetJointLocation, 创建人体, 女性, 身高, 位置
>
> **Verified on / 验证环境**: Process Simulate 2402.0, Windows 10, .NET Framework 4.8 / C# 5 (no string interpolation).
> Lengths are in **mm**, angles in **radians**.

---

## 1. Key facts / 关键结论

| # | Fact / 结论 |
|---|---|
| 1 | `TxHuman` has **no public creation method** (no factory, no `Create...` member). A new human is created through the built-in **Create Human** command, not by `new TxHuman(...)`. `TxHuman` 没有创建方法，只能走内置 Create Human 命令。 |
| 2 | The built-in command may open a **modal dialog** (e.g. the default female model is not in the library). While it is open, the UI thread is blocked and every following API call hangs. The user must click OK. 命令可能弹出模态对话框，期间 UI 线程被阻塞，后续 API 调用会挂起，需要用户点 OK。 |
| 3 | Right after the command returns, polling may report **"no new human appeared"** even though the human is created once the dialog is closed. **Re-list all `TxHuman` objects before retrying**, otherwise you create duplicates. 命令刚返回时可能检测不到新人体，重试前先重新列出人体，避免重复创建。 |
| 4 | The default female created in this install is named **Jill**, default height **163 cm**. It spawns at the world origin, not at the existing human. 默认女性名为 Jill，身高 163 cm，生成在世界原点。 |
| 5 | After the height was set to 180 cm the read-back was **180.00003 cm** (float rounding is normal). 设置 180 cm 后回读为 180.00003 cm。 |
| 6 | Copying the `AbsoluteLocation` of the reference human matched its location matrix to ~6.6e-33. 复制参考人体的 `AbsoluteLocation` 后矩阵误差约 6.6e-33。 |
| 7 | **Pitfall – feet below floor.** The human origin is at pelvis height. Copying the origin Z of a 175 cm Jack onto a 180 cm Jill put her toes ~110 mm lower (Jack toes Z = 13.1, Jill toes Z = -97.5). After copying the location, shift Z by `dz = toeZ(reference) - toeZ(new)` (about +110.5 mm here). 复制位置后，更高的人体脚会陷入地面，需要按脚趾高度差补偿 Z。 |

## 2. Recommended workflow / 推荐流程

1. **Preflight (read-only)**: list all humans (name, id, height proxy, `AbsoluteLocation`); confirm the reference human exists.
2. **Create** the human with the built-in Create Human command, gender = female. Warn the user that a dialog may appear.
3. **Re-list** humans; the new one is the id that was not in step 1. Do not create again if it is there.
4. **Set height** (cm → the unit your height call expects) and read it back.
5. **Locate**: copy the reference human's `AbsoluteLocation`.
6. **Ground-align**: shift Z by the toe-height difference (fact 7).
7. **Verify**: gender, id, height, location matrix, toe Z. Do not save the Study unless the user asks.

## 3. Verified API snippets / 已核对的 API 片段

```csharp
// Find a human by name
TxHuman FindHuman(TxDocument doc, string name)
{
    foreach (ITxObject item in doc.PhysicalRoot.GetAllDescendants(new TxTypeFilter(typeof(TxHuman))))
    {
        TxHuman h = item as TxHuman;
        if (h != null && string.Equals(h.Name, name, StringComparison.OrdinalIgnoreCase)) { return h; }
    }
    return null;
}

// Average of two joints (e.g. both toes) in world coordinates
TxVector Avg(TxHuman h, string a, string b)
{
    TxVector p = h.GetJointLocation(a);
    TxVector q = h.GetJointLocation(b);
    return new TxVector((p.X + q.X) / 2.0, (p.Y + q.Y) / 2.0, (p.Z + q.Z) / 2.0);
}

// Place the new human at the reference human's location, then fix the ground level
newHuman.AbsoluteLocation = new TxTransformation(reference.AbsoluteLocation);
double dz = Avg(reference, "right_toes", "left_toes").Z - Avg(newHuman, "right_toes", "left_toes").Z;
if (Math.Abs(dz) > 0.5 && Math.Abs(dz) < 300.0)
{
    TxTransformation t = new TxTransformation(newHuman.AbsoluteLocation);
    TxVector tr = t.Translation;
    t.Translation = new TxVector(tr.X, tr.Y, tr.Z + dz);
    newHuman.AbsoluteLocation = t;
}
TxApplication.RefreshDisplay();
```

## 4. Useful human data / 人体数据备忘

- `TxHuman` joint names (80): `right_toes, left_toes, right_ankle, left_ankle, right_knee, left_knee, right_hip, left_hip, atlanto_occipital, base_of_neck, waist, solar_plexus, left_clavicle_joint, right_clavicle_joint, left_shoulder, right_shoulder, left_elbow, right_elbow, left_wrist, right_wrist, ...` (spine, fingers, eyes, ears, hair, couples). `*_couple` joints are virtual: `GetJointLocation` throws `TxException`, catch it.
- **Facing direction**: the human local +X is the facing direction. Both Jack and Jill had `RotationRPY_XYZ = (0, 0, -1.5706)`, so they faced world **-Y** and their left side was world **+X**. Derive it from the joints, not from an assumption: `heading = atan2(toes.Y - ankles.Y, toes.X - ankles.X)`; left = `(-sin(heading), cos(heading))`.
- `TxHumanWalkMode` values: `Automatic=1, Forwards, Backwards, Sideways`.
