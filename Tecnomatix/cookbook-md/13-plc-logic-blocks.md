## 1. Create a PLC Logic Behavior

```csharp
TxPlcLogicBehaviorCreationData data = new TxPlcLogicBehaviorCreationData(name);
ITxPlcLogicBehaviorCreation creator = owner as ITxPlcLogicBehaviorCreation;
if (creator.CanCreateLogicBehavior(data))
{
    TxPlcLogicBehavior plb = creator.CreateLogicBehavior(data);
    // create entry/exit sub-behaviors, then add expressions (see below)
}
```

## 2. ⚠️ Complex expressions: use `AddLogicBehaviorExpression`, NOT `.Add(string)`

For any expression with operators/parentheses (NOT / AND / OR / `(...)`), `.Add(string)` produces a
block that shows "INVALID EXPRESSION" after the study is saved and reopened. Use
`AddLogicBehaviorExpression(plb, expr)` instead.

```csharp
// ❌ Wrong for complex expressions — breaks after save/reopen
plb.Add("NOT (A AND B) OR C");

// ✅ Correct
TxPlcExpression expr = /* build the expression object, see §3 */;
plb.AddLogicBehaviorExpression(plb, expr);
```
- `AddLogicBehaviorExpression` was introduced in version **2408** — earlier versions cannot correctly
  persist complex expressions via the API.
- 来源 / Source (forum): <https://community.sw.siemens.com/s/question/0D5Vb00000imqm9KAA/>
  (invalid expression) and related "INVALID EXPRESSION" threads.

## 3. Build an expression from a string (TxPlcExpressionBuilder)

```csharp
TxPlcExpressionBuilder builder = new TxPlcExpressionBuilder();
TxPlcExpression expr = builder.CreateExpression(expressionString);   // parse string -> expression
// Then attach via AddLogicBehaviorExpression (see §2).
```

## 4. ⚠️ Set the display units of a logic block (angular = DEGREE)

There is no direct API to set a logic block's angular display units; API-created blocks default to
radians. Workaround — edit the object's `.gmPlc` / XML resource:

```
Data > Objects > PlcLogicBehavior > Units > Angular = "DEGREE"   // (or "RADIAN")
```
- Edit the resource XML, then re-import/attach it. Confirmed workaround on the forum.
- 来源 / Source (forum): <https://community.sw.siemens.com/s/question/0D5Vb00000gKSeKKAW/> —
  "How to set the display units of a logic block".

## API quick reference / 速查
| Member | Use |
| --- | --- |
| `TxPlcLogicBehaviorCreationData` | logic behavior creation data |
| `ITxPlcLogicBehaviorCreation.CanCreateLogicBehavior` / `CreateLogicBehavior` | create behavior |
| `TxPlcExpressionBuilder` / `TxPlcExpression` | build expression objects |
| `plb.AddLogicBehaviorExpression(plb, expr)` | attach complex expression (v2408+) |
| gmPlc XML `Units > Angular` | display-unit workaround |
